# TerraEyes — Geospatial Semantic Retrieval & Multi-Temporal Change Analysis

TerraEyes is an offline-first geospatial intelligence platform designed for semantic retrieval of satellite imagery and multi-temporal change detection using State Space Models (Mamba) and satellite feature extraction pipelines.

## Repository Structure

- **`setup/`**: Setup documentation, environment configuration, dependency management, and coding standards.
- **`frontend/`**: React + TypeScript + Vite UI supporting query input, image comparison, and change mask overlays.
- **`backend/`**: FastAPI modular monolith handling search orchestration, vector retrieval, DB persistence, and ML model inference.
- **`data-handling/`**: Satellite data ingestion pipelines, sensor adapters (Sentinel-2, Sentinel-1, Landsat), preprocessing, and tiling.
- **`docs/`**: API references, architecture decision records (ADRs), and model registries.

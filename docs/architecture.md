# TerraEyes Architecture Document

## System Overview
TerraEyes is an analyst-oriented geospatial intelligence platform operating entirely offline after deployment. It supports multi-sensor satellite imagery ingestion, natural language & visual semantic retrieval, bi-temporal change detection, and structured reporting.

## Storage Architecture
1. **Relational & Spatial Store (SQLite)**: Stores tile metadata, geographic bounding boxes, resolution, timestamps, and sensor provenance.
2. **Vector Index (FAISS)**: Offline inner-product / cosine similarity index for global vision-language embeddings.
3. **Temporal State Store (HDF5 / Persistent)**: Stores recurrent Mamba state space representations across acquisition dates.
4. **Mask Cache**: Stores binary change masks generated by the detection service.
